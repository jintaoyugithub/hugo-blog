# Atomic Habits

这是我第二次看这本书了，第一次看的时候有点像为了完成任务而去看的，也没有真正去实践书中提到的方法。我也尝试过养成类似早睡早起，睡前看书等习惯，有一段时间我一直是早上五点半就起床，睡前的娱乐活动是看看书，坚持了大概三个月吧，直到暑假开始实习，一旦压力大起来，晚上想要暗示入睡就变得非常困难了，加上报复性的玩手机看视频，希望拿回一点属于我的时间，一点点的我的作息习惯又变成了以前2点睡，我曾试着就算晚睡我也在五点半左右醒，但“年迈”的身体已经不允许我这么做了。

但是我一直希望能够养成良好的习惯，小的时候没注意，长大了才知道持久的好习惯是多么的难能可贵，所以才有了这本书的第二次阅读。

第一章讨论更多是基本的原理，为什么微习惯，1%的改变很重要以及他最后是怎么影响我们的行为的。书中也举了很多例子，比如英国的自行车车队，聘请新的教练，从细小的地方开始改进，坐垫的舒适性，轮胎的摩擦力等等，终于在五年的奥运会上拿到成绩。对于当下的我来说，我目前的心态也很有问题，非常的急于求成，如果我做一件事情我非常希望我马上就能得到结果，特别是那种我能看得到结果就在眼前我马上就能解决的事情。就比如说配置我的终端文件，有时候我总在一些不是特别重要的事情上花费很多的时间，而导致更重要的事情没有时间去做了，**也许我可以好好利用这一点，更好的规划重要事情的推进步骤，充分利用我这种性格**。

其实书中提到的很多概念我都是或多或少早就明白的道理，但是很多时候很难去意识到我当下的处理方式是不符合我明白的道理的。就比如说书中提到的关于`目标与体系`的概念，说白了就是不要太过于关注目标是否完成，而是专注于当下，我不知道从多少本书中都看到了类似的观点，但是放到实际生活中，想要真正应用这些概念还是有些困难的，毕竟我设计出来这样的体系，本身就是为了达到这个目标，理所应当的我会不由自主的关注，离这个目标还有多远，还有多少我才能达成这个目标，但对于**长期的习惯养成**， 太过关注于目标确实不是一件好事，因为这就必须要求我们有较强的**延迟享乐**的能力了，而缺乏这种能力很多时候就是导致习惯养成失败的原因了。

书中还提到了一个概念也挺有意思的，就是**我们很多时候只会去解决不好的结果，而没有进一步的思考产生这些坏结果的根源是什么**，就好比我们总会过一段时间就进行一次大扫除，但是没想过造成房间非常乱的原因是因为我们没有一个良好的整理习惯。
